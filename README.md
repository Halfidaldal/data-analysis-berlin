# PENPAL — Berlin corpus

German-language turn-based collaborative storytelling data from the Berlin collection,
processed through the PENPAL pipeline.

> **Status: pre-paper.** No paper has been written on this corpus yet, and the analysis
> is expected to change. Nothing here should be treated as a settled result. There is
> currently **no analysis code** in this repository — only the corpus, the processed
> feature tables, and the pipeline that produced them.

## Layout

```
data/berlin/interim/     filtered stories (field + simulated baseline)
data/berlin/processed/   embeddings, valence, novelty, surface metrics
scripts/                 numbered pipeline (raw -> interim -> processed)
src/nes/                 pipeline modules
config.yaml              pipeline parameters, Berlin experiment only
```

Files with a `_simulated` suffix are the AI–AI simulated baseline generated by
`scripts/05_simulate_baseline.py`, not collected data.

The `_jina_field_` embedding files are from an earlier run with a different encoder and
are kept for comparison; `jinaai/jina-embeddings-v3` is still the configured embedding
model for this corpus, since the stories are in German.

## Differences from the English PENPAL conditions

| | Berlin | human-ai / human-human / ai-ai |
|---|---|---|
| language | German | English |
| turns per story | 5 | 10–11 |
| min interactions | 5 | 7–9 |
| embeddings | `jinaai/jina-embeddings-v3` | `Kingsoft-LLM/QZhou-Embedding` |
| sentiment | `ssary/XLM-RoBERTa-German-sentiment` | mpnet concept projection |

The shorter stories and the different encoder mean Berlin numbers are not directly
comparable to the English conditions without care.

## Running the pipeline

```bash
pip install -r requirements.txt
python scripts/03_compute_embeddings.py
python scripts/04_compute_sentiment.py
python scripts/06_compute_textdescriptives.py
python scripts/07_compute_novelty.py
python scripts/08_compute_semantic_exploration.py
```

`config.yaml` has a single experiment, `berlin`, already set as `active_experiment`.

Raw Firestore exports are excluded — they carry unredacted participant text and
respondent identifiers. Scripts 01–02 document how `interim/` was produced but need
credentials plus the raw export to run. Scripts 03 and 07 need a GPU to be practical.
